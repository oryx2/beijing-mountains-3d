# 北京山川地理 · 3D 网页

宏观山川视角：看西山、军都山、永定河、潮白河与市域落位（非行政区划图）。

## 打开方式

在本目录启动静态服务后用浏览器访问：

```bash
cd /workspace/beijing-terrain/web
python3 -m http.server 8080
# 浏览器打开 http://127.0.0.1:8080/
```

不要直接双击 `index.html`（浏览器会拦截本地 GLB 加载）。

## 操作

- 拖动：旋转 · 滚轮：缩放 · 右键：平移
- 「重置视角」：南望北默认俯瞰
- 悬停山 / 湖河圆点看名称；区名淡显作方位参考
